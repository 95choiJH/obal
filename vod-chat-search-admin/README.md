# 치지직 VOD 채팅 검색 — 관리자용

치지직 다시보기 페이지에서 키워드가 포함된 채팅을 찾고 해당 영상 시점으로 이동하는 로컬 전용 Chrome/Firefox 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `vod-chat-search-admin` 폴더를 선택합니다.

치지직의 `https://chzzk.naver.com/video/{번호}` 페이지에서 오른쪽 아래 **채팅 검색** 버튼을 사용합니다.

## 동작

- 검색할 때만 VOD 채팅을 순차적으로 조회합니다.
- 키워드와 선택적 닉네임 필터를 브라우저 안에서 적용합니다.
- 결과를 누르면 페이지의 영상 플레이어가 해당 시점으로 이동합니다.
- 채팅 내용은 별도 서버나 파일에 저장하지 않습니다.
- 검색 중 **중단**을 누르면 다음 페이지 요청 전에 작업을 멈춥니다.

## 제약

치지직 웹 서비스가 사용하는 비공개 VOD 채팅 엔드포인트에 의존합니다. 치지직이 응답 구조를 바꾸면 수정이 필요합니다. 채팅 다시보기가 없거나 접근 권한이 없는 VOD는 검색할 수 없습니다.
