개인정보처리방침

현재 오뱅알의 구현을 기준으로 어떤 데이터가 처리되는지 안내합니다.

작성일: 2026년 9월 18일

이 문서는 현재 구현을 바탕으로 작성한 초안입니다. 운영자 연락처, 서버 저장 지역, 보관 기간 및 위탁·국외 이전 사항을 확정한 뒤 운영용 방침으로 최종 검토해야 합니다.

웹앱 접속

호스팅 서비스는 페이지 제공과 보안을 위해 IP 주소와 요청 정보를 로그로 처리할 수 있습니다. 모바일 웹앱에는 회원가입 또는 별도의 방문 분석 스크립트가 없습니다.

모바일 웹앱과 확장 프로그램

일반 시청자는 Riot 계정 로그인이나 게임 계정 비밀번호를 제공하지 않습니다. 모바일 웹앱은 방송 일정·소식과 등록된 스트리머의 롤 티어·전적을 서버에서 조회하며 서비스 워커를 통해 앱 파일을 브라우저에 캐시합니다. 확장 프로그램은 표시할 채널을 현재 치지직 페이지에서 확인하고 일정·소식·전적을 조회합니다. 확장 프로그램 설정과 조회 데이터의 캐시는 브라우저 로컬 저장소에 저장됩니다.

문의·제보 접수

PC 확장 프로그램에서 문의·제보를 제출하면 분류, 내용, 관련 링크와 확장 프로그램 버전이 서버로 전송될 수 있습니다. 연락처 입력을 사용하는 경우 입력한 연락처도 포함됩니다. 해당 데이터는 문의 확인과 답변, 일정 수정 및 오류 대응을 위해 Supabase에 저장됩니다.

서버는 과도한 요청을 제한하기 위해 요청 IP에서 생성한 해시 식별자를 사용할 수 있습니다. 문의에 계정 비밀번호, API 키 또는 불필요한 개인정보를 포함하지 마세요.

리그 오브 레전드 데이터

운영자가 연동한 스트리머 계정의 Riot ID와 계정 식별자, 현재 티어·LP 및 솔로 랭크 경기 정보를 Riot API를 통해 서버에서 수집합니다. 경기 ID, 플레이 시각, 챔피언, 포지션, 승패와 경기 통계는 전적과 요약 표시를 위해 저장됩니다. Riot API 키는 서버 비밀 설정에 보관하며 시청자에게 제공하는 확장 프로그램에 포함하지 않습니다.

저장과 접근

문의와 서비스 데이터는 Supabase를 사용해 저장합니다. 서비스 수정과 문의 관리에는 관리자 인증 및 접근 권한이 적용됩니다. 브라우저에 저장된 캐시는 사이트 데이터 삭제 또는 확장 프로그램 삭제로 정리할 수 있습니다.

서버 데이터의 정확한 보관 기간, 저장 지역, 처리 위탁 및 국외 이전에 관한 사항은 운영자가 배포 환경을 확인한 후 확정해야 합니다. 이 초안은 해당 사항이 확정됐다는 의미가 아닙니다.

문의와 삭제 요청

본인과 관련된 정보의 정정·삭제 요청이나 데이터 처리 문의는 PC 확장 프로그램의 ‘문의·제보’로 접수할 수 있습니다. 별도의 운영자 연락처는 최종 방침에서 안내할 예정입니다. 확장 프로그램 하단의 ‘문의·제보’ 버튼을 열고 내용을 작성해 주세요. 요청에는 확인에 필요한 최소한의 내용만 포함해 주세요.
