이용약관

오뱅알 모바일 웹앱과 PC 확장 프로그램의 제공 기능 및 이용 방법을 안내합니다.

작성일: 2026년 9월 18일

서비스와 제공 범위

오뱅알은 등록된 치지직 채널의 방송 일정과 소식을 제공합니다. 모바일 웹앱과 PC 확장 프로그램에서는 연동된 스트리머 계정의 리그 오브 레전드 솔로 랭크 전적과 티어 정보를 표시합니다.

계정과 설치

일반 시청자는 오뱅알 회원가입이나 Riot 계정 로그인 없이 사용할 수 있습니다. PC 기능에는 브라우저 확장 프로그램 설치가 필요하며, 모바일 일정은 브라우저에서 확인할 수 있습니다. 지원 채널과 계정은 운영자가 관리합니다.

정보의 갱신

방송 일정은 확인 가능한 정보를 바탕으로 정리하지만 실제 방송과 다를 수 있습니다. 경기 기록은 Riot API 응답과 수집 시점에 따라 지연되거나 누락될 수 있습니다. 티어 변화는 실제 수집한 티어·LP 기록을 사용하며 수집 이전의 당시 LP를 복원하거나 추정해 표시하지 않습니다.

이용 시 지켜주세요

  • 문의·제보에는 관련된 내용을 작성하고 다른 사람의 개인정보나 계정 비밀번호, API 키를 올리지 마세요.
  • 서비스의 인증과 접근 제한을 우회하거나 반복 요청으로 정상 운영을 방해하지 마세요.
  • 서비스 화면에 표시되는 제3자의 콘텐츠와 상표는 해당 권리자의 권리를 존중해 사용하세요.

서비스 변경과 문의

외부 API 정책, 브라우저 지원 또는 운영 상황에 따라 제공 기능과 지원 범위가 변경될 수 있습니다. 오류·일정 제보와 운영 관련 문의는 PC 확장 프로그램의 ‘문의·제보’를 이용하세요. 접수 방법은 문의 안내에서 확인할 수 있습니다.

독립 서비스 안내

오뱅알은 치지직 또는 Riot Games의 공식 서비스가 아닙니다. Riot Games의 보증을 받지 않으며 관련 회사나 제품 관계자의 견해를 대변하지 않습니다. Riot Games 및 관련 제품의 상표권은 Riot Games, Inc.에 있습니다.
